# BrowOS 0.2

1. Open `brave://extensions`, turn on **Developer mode**, click **Load unpacked**, choose this folder.
2. Open a new tab. If Brave shows its own page, check `brave://settings/newTab` and make sure it is not forcing a different page.
3. Right-click the desktop for shortcuts. Add your own apps in Settings -> Web apps.

Frame-header stripping is limited to sub-frames opened by this extension, on hosts of apps you added.
